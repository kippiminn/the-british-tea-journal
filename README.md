# The British Tea Journal

Многостраничный русскоязычный исторический журнал о чае и британской культуре.

## Просмотр локально
Откройте папку проекта в редакторе (например, VS Code) и запустите локальный сервер. Самый простой способ — расширение Live Server, затем нажать правой кнопкой на `index.html` → Open with Live Server.

## Публикация
Загрузите содержимое папки проекта в корень репозитория GitHub и включите GitHub Pages (Settings → Pages → Deploy from a branch → main → /(root)).

## Примечание
Некоторые фотографии и веб-шрифты загружаются из интернета и требуют подключения. Основные страницы, стили и интерактивность находятся в локальных файлах.
